# 90 Anos Maria Luisa - Galeria de Foto

Este é um aplicativo simples, elegante e responsivo criado para exibir e baixar a foto restaurada do aniversário de 90 anos da Maria Luisa.

## Como colocar a sua foto real

1. Vá até a pasta `public` na raiz deste projeto.
2. Coloque a sua foto restaurada lá dentro.
3. Renomeie a foto exatamente para **`foto-restaurada.jpg`** (ou altere o nome no arquivo `src/App.tsx` na linha 7 para o nome do seu arquivo).

*Nota: Enquanto você não colocar a foto lá, o app exibirá uma imagem de exemplo antiga e bonita para você ver como fica o layout.*

## Como subir para o GitHub

1. Crie um repositório vazio no seu GitHub.
2. No terminal do seu computador, abra a pasta deste projeto e rode os comandos:
   ```bash
   git init
   git add .
   git commit -m "Versão inicial: App 90 anos Maria Luisa"
   git branch -M main
   git remote add origin URL_DO_SEU_REPOSITORIO_NO_GITHUB
   git push -u origin main
   ```

## Como publicar no Vercel (De graça e muito rápido)

O Vercel tem suporte nativo para projetos Vite (React), que é a tecnologia usada aqui.
1. Crie uma conta no [Vercel](https://vercel.com/) (você pode logar direto com o seu GitHub).
2. No painel do Vercel, clique em **"Add New..." > "Project"**.
3. Importe o repositório do GitHub que você acabou de criar.
4. O Vercel vai detectar automaticamente que é um projeto Vite. Não precisa mudar nenhuma configuração.
5. Clique em **Deploy**.
6. Em menos de 1 minuto, seu site estará no ar com um link público pronto para mandar para a família!
